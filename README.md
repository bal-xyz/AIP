# AIP 脉冲 · AI 热点情报台

一个本地优先、可部署到单机服务器的 X（原推特平台）与抖音公开内容监控系统。页面只显示采集器写入的真实作品；采集不完整时明确显示数据缺口，不使用模拟帖子补位。

## 当前结果

- **热点**：按主体、具体变化和 72 小时窗口聚合多作者帖子；单作者或单条爆款不会形成行业热点。
- **热帖**：使用 R（作者内相对倍数）、M（赞粉比）和 Tier（账号体量层）生成 T1（小爆）至 T3（现象级），与实时动量分开显示。
- **关注**：展示关注博主的新作品和真实指标；中文博主允许保留非人工智能生活内容。
- **分析**：L1（一级快评）自动入队，L2（二级深析）默认手动；相关性复核、事件归并复核和 ASR（语音识别）均预留独立路由。

## 本地启动

环境要求：Node.js 22（服务运行环境）、Chrome（谷歌浏览器）。

```bash
npm install
npm run migrate:dry-run
npm run migrate
npm start
```

也可双击 `start.command`。页面地址为 `http://127.0.0.1:4173`。

随后在 Chrome（谷歌浏览器）的“扩展程序”页面开启开发者模式，加载 `extension/` 目录，并分别登录 X（原推特平台）和抖音。点击扩展图标可以配置本地或云端地址、节点标识和一次性显示的节点令牌，也可以立即执行队列。扩展每分钟自动领取任务。

## 数据与迁移

- 正式数据库：`data/aip-monitor.sqlite`，使用 SQLite（嵌入式数据库）和 WAL（预写日志）模式。
- 旧版 `data/state.json` 可作为一次性迁移输入；当前项目已完成迁移，不再保留该影子文件。
- 备份：`npm run backup`，输出到 `data/backups/` 并自动执行完整性检查。
- 旧 Skill（技能）数据在迁移时只归档，不运行、不暴露接口。
- 旧热门词、旧事件和帖子内旧派生分析也只读归档，再从原始帖子与快照按新规则重算。
- 七天以上的细粒度快照会事务压缩为按日汇总；冻结等级证据保留独立数值副本。

迁移先执行只读预检，再导入；作品以“平台 + 平台作品标识”保持唯一。采集结果还需要匹配节点、租约代次和载荷哈希，迟到或冲突结果会被拒绝并记入审计。

## 模型接口

在页面“管理 → 模型接口”中配置任务路由、供应商、模型、接口地址、计价版本和预算参数。页面不接受明文密钥；密钥名称填写环境变量，例如：

```bash
export DEEPSEEK_API_KEY="..."
export OPENAI_API_KEY="..."
```

支持 Responses API（响应接口）与 OpenAI 兼容的 Chat Completions API（聊天补全接口）。L1（一级快评）默认每日预算 0.50 美元、最多 100 个内容版本，可用 `AIP_L1_DAILY_USD` 和 `AIP_L1_DAILY_VERSIONS` 调整。预算在请求前事务预留，失败也会结算已消耗的预留额，避免并发超支。

## 服务器部署

单实例服务器可继续使用 SQLite（嵌入式数据库），前提是挂载持久化磁盘并只运行一个写实例：

```bash
cp .env.example .env
docker compose up -d --build
```

生产环境必须设置管理员密码、一次性引导采集令牌和允许的页面来源。引导令牌首次配对后即失效；后续节点应从“管理 → 采集状态”签发，支持单节点轮换、宽限和撤销。若未来要水平扩展多个服务实例，再迁移 PostgreSQL（关系型数据库）。

## 安全边界

- 只读取当前登录账号能够看到的公开内容，不点赞、评论、转发或发布。
- 页面管理员会话与扩展采集令牌完全分离；写接口在生产模式验证 CSRF（跨站请求伪造防护）令牌。
- 逐字稿媒体只允许 HTTPS（加密网页协议）和平台媒体域名，拒绝本机、私网及未知域名。
- 数据覆盖不足时暂停热点冷却等负向判断。
- 同一事件阶段只生成一次浏览器通知，阶段升级会产生新通知；通知权限由用户在管理页面主动开启。
