# AIP 双平台真实监控采集器

该扩展只读取 X（原推特平台）与抖音页面上已经公开、且当前登录用户能够看到的作品内容和互动数字，然后写入 AIP（人工智能脉冲）服务。不会发布、点赞、转发、评论或发送消息。

安装：Chrome → 扩展程序 → 管理扩展程序 → 开发者模式 → 加载已解压的扩展程序 → 选择本目录。

运行：保持 AIP（人工智能脉冲）服务开启，并在 Chrome（谷歌浏览器）分别登录 X（原推特平台）和抖音。扩展每分钟读取一次队列；点击扩展图标可配置服务并立即运行。

本地默认服务地址是 `http://127.0.0.1:4173`，默认开发采集令牌是 `local-dev-collector`。部署到云端时，可直接在扩展设置页填写 HTTPS（加密网页协议）服务地址、服务器签发的节点标识和采集令牌；扩展只会申请该域名的访问权限。节点令牌支持轮换和撤销，引导令牌首次配对后不再有效。

采集任务绑定扩展节点和一次性租约。租约过期、节点不一致或相同任务提交不同载荷时，服务器会拒绝结果，避免旧页面覆盖新数据。
